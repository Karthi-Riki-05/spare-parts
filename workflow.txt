===============================================================================
 1. PROJECT STRUCTURE
===============================================================================

spare-parts-verifier/
  backend/          Express.js API server (port 3001) — JS + EJS views
  frontend/         Next.js 14 App Router (port 3000) — TypeScript + Tailwind
  shared/types/     TypeScript interfaces shared by frontend
  e2e/              Playwright E2E browser tests
  docker-compose.yml    Dev Docker (both services)
  docker-compose.prod.yml   Production Docker


===============================================================================
 2. PREREQUISITES
===============================================================================

- Node.js 20+
- npm 10+
- Docker Desktop (for containerized runs)
- Git


===============================================================================
 3. FIRST-TIME SETUP
===============================================================================

# Clone and enter project
cd spare-parts-verifier

# Install ALL dependencies (root + backend + frontend)
npm run install:all

# Or install individually:
npm install                     # root (concurrently, playwright)
npm install --prefix backend    # backend dependencies
npm install --prefix frontend   # frontend dependencies

# Install Playwright browsers (for E2E tests)
npx playwright install chromium webkit

# Generate test fixture Excel files
cd backend && node tests/fixtures/create-fixtures.js
node tests/fixtures/create-large-fixtures.js
cd ..

# Configure environment
# Backend .env is at: backend/.env
# Frontend .env is at: frontend/.env.local
# MOCK_MODE=true means no real AI API keys needed


===============================================================================
 4. RUNNING THE PROJECT
===============================================================================

--- Option A: Run both frontend + backend together ---

npm run dev

  This starts:
  - Backend on http://localhost:3001 (Express + EJS)
  - Frontend on http://localhost:3000 (Next.js)
  - Frontend proxies /api/* requests to backend automatically


--- Option B: Run backend only (EJS UI included) ---

npm run dev:backend

  Opens at: http://localhost:3001
  The backend serves its own EJS-based UI at the root URL.
  All API endpoints available at /api/*


--- Option C: Run frontend only (needs backend running separately) ---

npm run dev:frontend

  Opens at: http://localhost:3000
  Requires backend running on port 3001 for API calls.


--- Option D: Run with Docker ---

# Development (both services)
docker compose up --build

  Backend: http://localhost:3001
  Frontend: http://localhost:3000

# Stop Docker
docker compose down

# Production
docker compose -f docker-compose.prod.yml up --build -d


===============================================================================
 5. ENVIRONMENT VARIABLES (backend/.env)
===============================================================================

PORT=3001                       Server port
NODE_ENV=development            Environment (development/production/test)
CORS_ORIGIN=http://localhost:3000   Allowed CORS origin

# AI API Keys (not needed when MOCK_MODE=true)
OPENAI_API_KEY=your_key_here    GPT-4o-mini for format detection
GEMINI_API_KEY=your_key_here    Gemini 2.5 Flash for web verification
ANTHROPIC_API_KEY=your_key_here Claude Sonnet for rule enforcement

# Mock Mode — set true to develop without real API keys
MOCK_MODE=true                  Master switch (all AI services use mocks)
OPENAI_MOCK_MODE=false          Override: OpenAI only
GEMINI_MOCK_MODE=false          Override: Gemini only
CLAUDE_MOCK_MODE=false          Override: Claude only

# Processing
MAX_ROWS_WARNING=5000           Show warning dialog above this
MAX_ROWS_LIMIT=10000            Hard limit
BATCH_SIZE=5                    Rows per verification batch
MAX_CONCURRENCY=5               Parallel AI calls
REQUEST_TIMEOUT_MS=30000        API call timeout
MAX_RETRIES=3                   Retry count on failure
RETRY_DELAY_MS=1000             Initial retry delay (exponential backoff)
CACHE_TTL_SECONDS=86400         Cache duration (24 hours)

# Rate limiting
RATE_LIMIT_WINDOW_MS=900000     Window (15 minutes)
RATE_LIMIT_MAX=100              Max requests per window

# Logging
LOG_LEVEL=info                  Winston log level


===============================================================================
 6. API ENDPOINTS
===============================================================================

GET  /api/health          Health check
POST /api/get-sheets      Get Excel sheet names        { fileData: base64 }
POST /api/detect-format   Detect format (A/B/C)        { fileData, sheetIndex }
POST /api/normalize       Normalize Excel data         { fileData, sheetIndex, format }
POST /api/manual-map      Apply manual column mapping   { fileData, sheetIndex, mapping }
POST /api/verify          Verify parts (SSE stream)    { rows, batchSize }
POST /api/export          Export verified Excel         { results, originalData, fileName }

===============================================================================
 10. TROUBLESHOOTING
===============================================================================

Problem: "Too many requests" error during E2E tests
Fix:     Start backend with RATE_LIMIT_MAX=10000 node src/server.js

Problem: AI API calls fail
Fix:     Set MOCK_MODE=true in backend/.env (no real API keys needed)

Problem: Frontend can't reach backend API
Fix:     Ensure backend is running on port 3001
         Check CORS_ORIGIN=http://localhost:3000 in backend/.env

Problem: Docker build fails
Fix:     Run docker compose down && docker compose up --build

Problem: Playwright tests fail with "browser not found"
Fix:     Run npx playwright install chromium webkit

Problem: Test fixtures missing
Fix:     cd backend && node tests/fixtures/create-fixtures.js

Problem: Port already in use
Fix:     lsof -i :3001 (or :3000) then kill the process
