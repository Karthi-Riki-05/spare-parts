# Session Management Rules

## Suggest /clear when
- After completing any full feature
- Switching module (excel → AI → verify → export)
- After 20+ messages in same session
- User says "now let's work on X" (new topic)
- After running 2+ sub-agents

## Use /compact when
- Long session, same task continues
- Don't want to lose context entirely
- Mid-debug of one issue

## Token Saving Habits
- One feature per session
- /clear between unrelated tasks
- Fresh session = fresh context
- Re-read this file's referenced rule, not the whole codebase

## Branch Discipline
- main = production
- develop = active work
- Confirm branch before commits
